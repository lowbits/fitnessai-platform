## Project Overview

FitnessAI is a fitness planning and meal management web application with a React Native mobile app. The backend is Laravel 12 (PHP 8.2+) and the frontend is Vue 3 with TypeScript, connected via Inertia.js.

## Development Commands

```bash
# Full-stack development (recommended)
composer run dev          # Starts server, queue, logs, and vite concurrently

# Individual commands
php artisan serve         # Laravel server
npm run dev               # Vite dev server

# Testing
composer run test         # Clears config and runs Pest tests
./vendor/bin/pest         # Run tests directly
./vendor/bin/pest tests/Feature/SomeTest.php  # Single test file
./vendor/bin/pest --filter="test name"        # Single test by name

# Linting and formatting
npm run lint              # ESLint fix
npm run format            # Prettier format
vendor/bin/pint           # PHP code style (Laravel Pint)

# Build
npm run build             # Production build
npm run build:ssr         # Production build with SSR
```

## Architecture

### Backend (`/app`)

- **Actions/** - Business logic/service layer for complex operations
- **Http/Controllers/Api/V2/** - Mobile API endpoints (all under `/api/v2` prefix)
- **Jobs/** - Queued background jobs:
  - `GenerateUserWorkoutPlan` - AI-powered workout plan generation (complex, ~35KB)
  - `GenerateUserMealPlan` / `GenerateMealPlanBatch` - AI meal planning
  - `ReplaceMealJob` - Meal replacement logic
  - `SendAppPromoNotificationJob` - Marketing push notifications
- **Models/** - Eloquent models for User, Plan, WorkoutPlan, MealPlan, Meal, Exercise, etc.
- **Notifications/** - Multi-channel notifications (email, push via Expo)
- **Services/** - External integrations (OpenFoodFacts, notification services)

### Frontend (`/resources/js`)

- **pages/** - Vue page components (routed via Inertia.js)
- **components/** - Reusable Vue components (uses shadcn-vue/Reka UI)
- **composables/** - Vue composition functions
- **i18n/** - Internationalization files
- **routes/** - API route type definitions (auto-generated by Wayfinder)
- **wayfinder/** - Auto-generated route helpers from Laravel routes

### Key Integrations

- **OpenAI** - Workout and meal plan generation via `openai-php/laravel`
- **Expo Push** - Mobile notifications via `laravel-notification-channels/expo`
- **RevenueCat** - Subscription management via webhooks
- **Meilisearch** - Full-text search
- **DOMPDF** - PDF generation for plans

## API Structure

All mobile API endpoints are under `/api/v2`:
- Auth: `/auth/login`, `/auth/me`, `/auth/logout`
- Plans: `/plan/day/{date}`
- Meals: `/meals/{id}`, `/meals/{id}/alternatives`, `/meals/{id}/replace`
- Workouts: `/workouts/{id}`, `/workouts/{id}/reschedule`, `/workouts/{id}/skip`
- Tracking: `/track/workouts`, `/track/calories`, `/track/body-progress`
- Notifications: `/notifications/register-token`, `/notifications/remove-token`

Authentication uses Laravel Sanctum tokens.

## Testing

- Framework: Pest (PHPUnit-based)
- Test database: SQLite in-memory (configured in `phpunit.xml`)
- Feature tests in `tests/Feature/`, unit tests in `tests/Unit/`

## Code Style

- PHP: PSR-12 via Laravel Pint
- TypeScript/Vue: ESLint + Prettier
- Prettier plugins auto-organize imports and sort Tailwind classes
- Path alias: `@/*` maps to `resources/js/*`
